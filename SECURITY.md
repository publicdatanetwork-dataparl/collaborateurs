# Sécurité

## Signaler une vulnérabilité

Tu as trouvé une faille de sécurité sur ce dépôt ou sur un des services de
DataParl' ? Merci de **ne pas ouvrir d'issue publique** et d'écrire plutôt à :
**https://www.dataparl.fr/contact** (PGP disponible sur demande).

Nous nous engageons à :

- accuser réception sous **72 heures** ;
- tenir informé·e de l'avancement jusqu'à la correction ;
- créditer (si souhaité) la personne qui a signalé.

## Périmètre

En périmètre : le code de ce dépôt, sa configuration de déploiement, le
traitement des données personnelles qu'il manipule.

Hors périmètre : les attaques par déni de service, le spam, les tentatives
d'hameçonnage génériques, les problèmes sur des versions non déployées.

## Bonnes pratiques de signalement

Indique, si possible : les étapes pour reproduire, l'impact estimé, un
proof-of-concept. Ne teste jamais sur des données réelles d'utilisateurs :
utilise un compte de test.

## Divulgation coordonnée

Merci de laisser un délai de **90 jours** avant toute publication publique
du détail de la faille, pour laisser le temps de corriger et de déployer.
